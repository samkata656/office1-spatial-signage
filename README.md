# Samsung Spatial Signage SMHX-P × Office 1 — B2B landing page (concept)

A one-page, interactive marketing page in Bulgarian. It presents the Samsung Spatial Signage SMHX-P (LH85SMHPBGCXEN) to Office 1 business clients.

- Plain static HTML/CSS/JS (`index.html`) with no build step. Images are in `assets/`.
- Interactive sections: a 3D depth lab, a before/after comparison slider, feature tabs, use-case explorer, a 360° product viewer, a size visualiser, filterable specs, and a demo lead form.
- **Concept only.** This is not an official Office 1 or Samsung page. The form does not send any data. Product images and specs © Samsung Electronics.

Run it locally: open `index.html` in a browser, or run `python3 -m http.server`.
